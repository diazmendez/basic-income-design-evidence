# S8 access statement: Vermont WRP restricted-use data (public)

Restricted-use data for the Vermont Welfare Restructuring Project are held as ICPSR Study 38060, under controlled-access requirements. Access is by secure download and requires:
- an ethics review document;
- a data-security plan;
- an institutional data-use agreement.

These data were **not accessed** in this study. They are **not treated as observed evidence**.

In the current audit, the WRP conditionality contrast keeps its frozen codes, taken from the published report: V = Y, I = PURE, E = E-A, U = STARS, usable_U = NO. Only significance stars are published, so the contrast has no usable uncertainty.

Whether an existing design could yield usable uncertainty through such a route ("analytical recoverability") is a descriptive observation. It is not an audit stage.

*Provenance.* This statement is derived from the project's private access record (D045). That record is not released, because its access-cost and personal-decision details are not needed for reproduction. This statement contains no correspondence.
